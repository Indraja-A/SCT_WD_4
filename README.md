# 🌿 Indu's Task Planner

## SkillCraft Technology - Web Development Internship

### Task 04 - To-Do Web Application

A modern and responsive **To-Do Web Application** developed as part of the SkillCraft Technology Web Development Internship.

The application helps users organize their daily tasks, set dates and times, track progress, edit tasks, and mark completed tasks.

---

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- ↩️ Mark completed tasks as pending
- 🗑️ Delete tasks
- 📅 Set task date
- ⏰ Set task time
- 📋 Organize tasks into All, Pending, and Completed
- 📊 Track overall progress
- 💾 Save tasks using Local Storage
- 🧹 Clear all completed tasks
- 🌱 Motivational productivity messages
- 📱 Responsive design
- 🎨 Modern and positive user interface

---

## 🎯 Task Objective

The objective of this task is to develop a basic To-Do web application that allows users to:

- Add tasks
- Maintain a task list
- Organize tasks
- Mark tasks as completed
- Edit existing tasks
- Set a date and time for tasks

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the web application
- **CSS3** – Styling, layout, responsive design, and visual effects
- **JavaScript** – Task management and application logic
- **Local Storage** – Persistent task storage
